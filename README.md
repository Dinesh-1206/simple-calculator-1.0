🧮 Simple Calculator

A simple and responsive Calculator Web App built using HTML, CSS, and JavaScript. This project provides a clean and easy-to-use interface for performing basic arithmetic calculations such as addition, subtraction, multiplication, and division.

🚀 Features
➕ Addition
➖ Subtraction
✖️ Multiplication
➗ Division
🔢 Decimal number support
🧹 Clear button
⌫ Delete/Backspace functionality
📱 Responsive design
⚡ Fast and easy to use
🎨 Simple and clean user interface
🛠️ Technologies Used
HTML5 – Structure of the calculator
CSS3 – Styling and responsive layout
JavaScript – Calculator functionality and calculations
📂 Project Structure
Simple-Calculator/
│
├── index.html
├── style.css
└── script.js
⚙️ How It Works
The user clicks the calculator buttons.
JavaScript captures the selected numbers and operators.
The entered expression is displayed on the calculator screen.
JavaScript performs the calculation.
The final result is displayed to the user.
💻 Run Locally

Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_URL
